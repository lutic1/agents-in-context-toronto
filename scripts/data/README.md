# Data scripts (prepared before the event)

These scripts were written before the event to download the open data in `data/`. They are kept in the repository as history, so the prepared work is disclosed.

On Saturday 14 November they must not be run, imported or copied into the project unless an organiser clears them in writing. The build writes its own code during the event, including the code that fetches the selected trials and the FDA list.

`data/README.md` describes what the scripts downloaded.
